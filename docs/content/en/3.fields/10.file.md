Because a `File` serializes to `{}` in JSON, the model panel beside it spells
the file out instead of lying that the field is empty.

## The basics

`accept` is required: it becomes the input's filter **and** the format badges
inside the dropzone itself.

## multiple

::demo{src="File/multiple" title="multiple" ui="grid gap-4 md:grid-cols-2"}
The model becomes an array of `File`. The type follows: `Element` receives
`(Multiple extends true ? File[] : File) | null` as its third parameter.
::
