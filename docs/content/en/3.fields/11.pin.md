Paste, backspace and arrow navigation work as in a single field — because the
model **is** a single field: the whole string, not an array of characters.

## type

::demo{src="Pin/type" title="numeric and alphanumeric"}
`numeric` takes digits only; `alphanumeric` takes letters too and shows them
uppercase.
::

::callout{type="warn"}
`type` lives **outside** `defaults.text`, next to Select's `keyValue` and
`keyLabel`. Inside, the auto-prefix would turn it into a translation key — and
the field would start comparing `"numeric"` with `"rform.fields.pin.numeric"`.
::

## secret

::demo{src="Pin/secret" title="secret"}
