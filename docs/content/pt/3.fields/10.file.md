Como um `File` serializa para `{}` em JSON, o painel de model ao lado o imprime
por extenso em vez de mentir que o campo está vazio.

## O básico

`accept` é obrigatório: ele vira o filtro do input **e** as badges de formato
dentro da própria dropzone.

## multiple

::demo{src="File/multiple" title="multiple" ui="grid gap-4 md:grid-cols-2"}
